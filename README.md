# SmartCart AI — GitHub Pages website

Responsive grocery shopping demonstration featuring vegetables, fruits, groceries, ready-to-cook items, dairy and household essentials.

## Launch locally
Open `index.html` in a browser, or right-click it in VS Code and select **Open with Live Server**.

## Publish using GitHub Pages
1. Create a **public** GitHub repository named `SmartCart-AI`.
2. Upload **the files inside this folder** (not the enclosing folder) to the repository root. `index.html` must appear at the root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; choose `main` and `/(root)`; then save.
5. After deployment, visit `https://YOUR-USERNAME.github.io/SmartCart-AI/` (replace YOUR-USERNAME).

## Included features
- Responsive product catalog, category filters, search and sorting
- Shopping cart and quantity controls, budget limit and savings hints
- Recipe-to-cart ingredient suggestions
- Context-aware promotional pop-ups and browser localStorage persistence

## Scope and limitations
This is a **front-end prototype** with illustrative catalog, prices, offers and inventory. Recommendations are rule-based; no trained AI model is bundled. There is no real checkout, payment, authentication, server or database. Do not enter sensitive personal information. See `docs/` for the project scope and manual test cases.
